# Серёга, начни здесь

NEURAL LIGHT превращает звук в свет. Уже можно выбрать эффект, менять цвет и яркость, смотреть подсветку в 3D, сохранять сцены и собирать свои эффекты. Для знакомства ESP32 не нужен. Для настоящей ленты понадобится контроллер с WLED.

Репозиторий содержит исходники. Приложение `build/NEURAL LIGHT.app` появляется после сборки на твоём Mac; скачивать папку `build` с GitHub не нужно.

## 1. Один раз подготовить Mac

Нужен Mac с Apple Silicon и macOS 14 или новее. Для разработки установи [Node.js](https://nodejs.org/en/download) **22.12 или новее** с npm и Apple Command Line Tools. Если используешь nvm, в папке проекта выполни `nvm install` и `nvm use`: версия указана в `.nvmrc`. [Google Chrome](https://www.google.com/chrome/) нужен для автоматических проверок интерфейса.

В Терминале:

```sh
xcode-select --install
```

Если инструменты уже установлены, повторная установка не нужна. После установки проверь:

```sh
uname -m
node --version
npm --version
swift --version
git --version
```

Для целевого Mac `uname -m` покажет `arm64`. Пакет Swift объявляет минимальную версию инструментов **5.9**; текущая сборка проверялась на **Swift 6.4.2**. Это разные вещи: прохождение проверки на каждой промежуточной версии не заявляется. При ошибке старого SDK обнови Command Line Tools или Xcode.

## 2. Получить проект и посмотреть свет

Если репозиторий приватный, сначала прими приглашение от Тихона в GitHub. Затем установи [GitHub CLI](https://cli.github.com/) и войди под аккаунтом, которому выдан доступ:

```sh
gh auth login
gh auth setup-git
```

Для публичного репозитория этот шаг не нужен. После этого скачай исходники:

```sh
git clone https://github.com/Tikhon00/neural-light.git
cd neural-light
npm ci
npm run dev
```

Открой [http://127.0.0.1:5173](http://127.0.0.1:5173). Терминал с `npm run dev` оставь открытым; `Control+C` останавливает сервер. Все следующие команды выполняются из папки `neural-light`.

На экране уже работает деморитм:

1. Выбирай эффекты в нижней панели, двигай яркость.
2. «Настроить» открывает палитру и скорость.
3. «Деморитм» открывает звук. Нажми «Послушать», если хочешь его слышать; по умолчанию свет работает без слышимого аудио.
4. «За монитором» — пример домашней установки. «Схема ленты» — координаты светодиодов. Потяни изображение, чтобы повернуть его; клавиша Home возвращает исходный ракурс.
5. «Сцены» хранит твои сохранения. Файлы из `examples/` открываются кнопкой «Открыть файл».

Браузерный режим нужен для быстрых правок и знакомства. Сам по себе он не отправляет кадры на WLED.

## 3. Собрать обычное приложение для Mac

В другом окне Терминала, из папки проекта:

```sh
npm run app:build
open "build/NEURAL LIGHT.app"
```

Скрипт собирает React и Swift/Metal, добавляет ресурсы и локальную подпись. После этого приложение работает без dev-сервера, Node и открытого Терминала. Интернет нужен для первого `npm ci`; модели, шрифты и интерфейс входят в сборку.

Если после изменения кода видишь старый интерфейс, полностью заверши NEURAL LIGHT через `⌘Q`, снова выполни `npm run app:build` и открой приложение. Горячее обновление есть у `npm run dev`, но не у уже собранного `.app`.

## 4. Подключить свою ленту

Сначала убедись, что лента работает из самого WLED. Mac и контроллер должны быть в одной локальной сети.

1. Открой собранное приложение для Mac.
2. В «Ещё → Расположение LED» укажи число светодиодов твоей ленты.
3. Поставь яркость около 15% для первого прогона.
4. Нажми «Подключить свою» над нижней панелью, затем «Добавить WLED». Введи адрес контроллера и число его LED.
5. В карточке устройства раскрой «Настройки устройства», проверь DDP и включи «Передавать свет».

Адрес нужно взять у твоего WLED; никакого адреса Серёгиной ленты в исходниках нет. После перезапуска отправка выключается, её нужно включить явно.

Подробности: [подключение и задержки](WLED.md). Первый реальный прогон делай по [аппаратной проверке](HARDWARE-CHECK.md): на момент передачи физические ESP32 ещё не проверялись. Счётчик отправленных пакетов не подтверждает, что лента показала кадр.

## Как продолжить с твоим Codex

Открой в Codex именно папку `neural-light`, чтобы агент видел корневой `AGENTS.md`, исходники и документацию. Скопируй этот запрос и замени последнюю строку своей задачей:

```text
Ты работаешь в репозитории NEURAL LIGHT. Сначала прочитай AGENTS.md,
README.md, docs/DEVELOPMENT.md и docs/UX-REVIEW.md. Посмотри текущие файлы,
git status и доступные инструменты; не считай проверки другой машины
результатом на моём Mac.

Делай изменения самостоятельно в пределах задачи. Сохраняй русский,
минималистичный интерфейс, прозрачные нейтральные панели, доступность
и плавность. Если меняешь эффекты или формат сцены, проверь соответствие
TypeScript, Swift CPU и Metal. Интерьерный 3D-пример не должен менять
физический mapping или кадры, отправляемые контроллерам.

Запусти подходящие проверки, собери приложение, если менялся его код,
и покажи скриншоты интерфейса прямо в ответе. Не создавай архивы.
Не включай микрофон, экран или вывод на устройства без моего выбора.
Отдельно напиши, что проверено и что остаётся непроверенным.

Моя задача: [что хочу изменить и какой результат хочу получить].
```

Для конкретной правки достаточно обычного запроса: «Сделай ещё один пример подсветки за телевизором, сохрани настройки и текущую схему LED». Агенту не нужно заново придумывать весь проект.

## Если что-то не запускается

| Что случилось | Что проверить |
|---|---|
| GitHub показывает 404 или `Repository not found` | Для приватного репозитория нужно принять приглашение и войти в GitHub под тем же аккаунтом; затем повторить клонирование. |
| `node: command not found` или ошибка версии Vite | Установлен ли Node 22.12+, затем снова `npm ci`. |
| `swift`/SDK не найден | Завершена ли установка Command Line Tools; что показывают `swift --version` и `xcode-select -p`. |
| Порт 5173 занят | Останови старый dev-сервер через `Control+C`. Не запускай два проекта на одном порту. |
| Приложение пишет об ошибке запуска движка | Полностью закрой другую копию приложения или отдельный engine; им нужны порты 8742/8743. |
| Переключатель «Передавать свет» недоступен | Открыт браузерный режим или потеряна связь с движком. Запусти `.app`; проверь «Ещё → Диагностика». |
| Изменения пропали после переключения браузер/приложение | У них раздельные сохранения. Перенеси сцену через JSON export/import. |
| Тесты интерфейса не находят браузер | Установи Google Chrome: тесты настроены на `channel: "chrome"`. |

Если ошибка остаётся, передай Codex точный текст ошибки, команду и версию macOS. Для WLED добавь версию прошивки, тип ленты и число LED; токены из локальных URL публиковать не нужно.
