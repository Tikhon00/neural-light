# Проверка глазами нового пользователя

14 ноября 2026. Это экспертный разбор и прохождение сценариев в приложении, а не исследование с приглашёнными пользователями. Проверены первый запуск без оборудования, выбор эффекта, настройка света, источник звука, сохранение и восстановление сцены, доступ к устройствам, клавиатура и узкий экран.

## Что уже было удачным

Живой свет сразу виден; яркость находится под рукой; основные эффекты выбираются одним нажатием. Профессиональные инструменты не занимают рабочее пространство. Прозрачные нейтральные панели и плавные переходы поддерживают ощущение цельного приложения.

## Что мешало и что изменено

| Проблема | Решение |
|---|---|
| Арки из точек не объясняют, как свет будет выглядеть дома. | Основной вид — объёмный макет рабочего места с подсветкой за монитором. «Схема ленты» остаётся отдельным видом реальных координат. |
| «Предпросмотр света» не объясняет отсутствие устройства; подключение спрятано. | Подпись «Виртуальная лента» и непосредственное действие «Подключить свою». При включённой отправке — «Передача на ленту включена», без обещания подтверждённой доставки. |
| «Демозвук» не слышно; на телефоне исчезает даже подпись. | Единое название «Деморитм», видимое на телефоне. Отдельная короткая панель объясняет беззвучную работу и содержит кнопку «Послушать». |
| Кнопка источника открывает сначала палитру и длинные настройки. | Открывает непосредственно «Звук и экран». Цвет и скорость остаются в «Настроить». |
| Иконку ползунков нужно угадывать. | Видимая подпись «Настроить» и на Mac, и на узком экране. |
| Большая библиотека повторяет шесть эффектов, пользовательские сцены ниже. | «Мои сцены» первыми, готовые эффекты компактнее и с описаниями поведения. Пустое состояние предлагает сохранить текущий свет. |
| Удаление сохранённого происходит без возможности передумать. | Действие «Вернуть» доступно в открытой библиотеке; не исчезает по таймеру. |
| Пауза может восприниматься как выключение ленты. | Подпись поясняет, что пауза оставляет свет включённым; 0% яркости явно отмечено как выключенный свет. |

## Визуальное решение

Сохраняем существующую систему: графит `#080a0d`, белый `#f5f6f8`, спокойные подписи `#aeb3bd`, фокус `#b9e5e4`. Системный шрифт для управления, более лёгкое начертание для названия эффекта, табличные цифры для яркости. Единственный выразительный объект — освещённое рабочее место; интерфейс не получает дополнительных цветных заливок.

Макет показывает пример установки. Он не перестраивает LED mapping, не меняет выходной кадр и не является расчётом освещённости комнаты. Нулевой уровень света убирает цветное излучение; слабое нейтральное освещение позволяет различать мебель. Орбитой управляет пользователь, автоматического вращения нет. Источники выбранных 3D skills: [3D-SKILLS-RESEARCH.md](3D-SKILLS-RESEARCH.md).

## Критерии проверки

- Пройти путь «эффект → яркость → сохранить → открыть» без технических параметров.
- Переключение вида не меняет число, расположение и слои LED, сохраняется после перезапуска.
- Восстановить удалённую сцену, не закрывая библиотеку; проверить результат после перезагрузки.
- Объяснение деморитма и его прослушивание доступны на 390 px; разрешения запрашиваются только при выборе микрофона или экрана.
- Панели не выходят за экран на 320/390/768 px; Escape и возврат фокуса работают; axe не находит нарушений WCAG A/AA.
- Стоимость нового 3D-предпросмотра измеряется отдельно от частоты нативного движка.

Следующая содержательная проверка с владельцем ленты — сможет ли он подключить свой WLED без помощи разработчика. Это остаётся непроверенным без оборудования.
