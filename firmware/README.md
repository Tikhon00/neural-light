# NEURAL LIGHT NODE

Своя прошивка приёмника света для классического ESP32 DevKit/WROOM, 4 МБ flash.

- [Установить через браузер](https://tikhon00.github.io/neural-light/)
- [Совместимость, настройка, сборка и проверки](../docs/FIRMWARE.md)
- [Правила для Codex](../AGENTS.md)

Первый target — `esp32dev`. Нужны RGB-лента и Mac-приложение NEURAL LIGHT; WLED не требуется. Работа на физической плате пока не проверена.
